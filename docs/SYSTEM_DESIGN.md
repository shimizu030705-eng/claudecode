# Meta広告キャンペーン自動作成・分析システム 設計書

## 1. システム概要

Google Apps Script (GAS) を使用して、Meta広告のキャンペーン作成から動画分析までを自動化するシステム。

### 1.1 処理フロー

```
[1] ドライブに動画を手動格納
        ↓
[2] スプレッドシートに動画URL・設定を入力
        ↓
[3] GAS実行
        ↓
    ┌───────────────────────────────────────┐
    │ [3-1] Meta広告に広告を出稿            │
    │ [3-2] videosタブに動画情報を自動記録  │
    │   - A列: 動画名                       │
    │   - B列: 固有ID (Meta video_id)       │
    │   - C列: 動画URL                      │
    │   - D列: アップ日                     │
    └───────────────────────────────────────┘
        ↓
[4] 動画の定性分析（Gemini API）
        ↓
[5] 分析結果をanalysisシートに出力
```

## 3. 機能一覧

### 3.1 メニュー機能

スプレッドシートを開くと以下のメニューが追加される：

```
Meta広告自動化
├── キャンペーン作成を実行
├── 動画分析を実行
├── シート初期設定
└── InstagramアカウントID取得
```

### 3.2 キャンペーン作成機能

1. キャンペーン設定シートから未処理のデータを取得
2. 各行について以下を実行:
   - 住所から緯度経度を取得（Geocoding API）
   - Drive から動画ファイルを取得
   - Meta に動画をアップロード
   - **videosシートに動画情報を自動記録**
   - キャンペーンを作成
   - 広告セットを作成
   - 広告クリエイティブを作成
   - 広告を作成
3. 処理結果をシートとログに記録
4. 通知メールを送信

### 3.3 動画分析機能

1. videosシートから分析対象の動画を取得
2. Gemini Files API に動画をアップロード
3. Gemini で動画を分析（定性評価）
4. 分析結果を analysisシートに記録

## 4. API連携

### 4.1 Meta Marketing API

- バージョン: v21.0
- エンドポイント:
  - `/act_{account_id}/campaigns` - キャンペーン作成
  - `/act_{account_id}/adsets` - 広告セット作成
  - `/act_{account_id}/adcreatives` - クリエイティブ作成
  - `/act_{account_id}/ads` - 広告作成
  - `/act_{account_id}/advideos` - 動画アップロード
  - `/act_{account_id}/adimages` - 画像アップロード

### 4.2 Gemini API

- モデル: gemini-2.5-flash
- エンドポイント:
  - Files API (アップロード)
  - generateContent (分析)

### 4.3 Google APIs

- Maps Geocoding API - 住所から座標取得
- Drive API - ファイル取得

## 5. エラーハンドリング

### 5.1 リトライ機能

- Meta API: 500/429エラー時に最大6回リトライ（指数バックオフ）
- Gemini API: ファイル状態確認で最大24回ポーリング

### 5.2 エラー通知

- 処理失敗時はシートにエラーメッセージを記録
- 設定されたメールアドレスに結果を通知

## 6. セキュリティ

### 6.1 トークン管理

- アクセストークンはスプレッドシートの共通設定シートで管理
- 本番運用時はスクリプトプロパティへの移行を推奨

### 6.2 権限

- スプレッドシートの編集権限を適切に設定
- Meta APIトークンの権限スコープを最小限に

## 7. 制限事項

- 動画ファイルサイズ: 最大200MB（Gemini分析時）
- 1回の実行で処理する動画数: 最大5件（タイムアウト対策）
- GAS実行時間制限: 6分（必要に応じて分割実行）
