# Meta広告自動化システム セットアップガイド

## 1. 前提条件

### 必要なアカウント・権限
- **Google アカウント**: Google Drive, スプレッドシート, GAS の利用
- **Meta Business Suite アカウント**: 広告アカウントへの管理者権限
- **Gemini API キー**: Google AI Studio で取得

### 必要な情報
1. **Meta広告アカウントID** (`act_XXXXXXXXXX`)
2. **FacebookページID**
3. **Instagramビジネスアカウントid** (Facebookページに連携済み)
4. **Meta Pixel ID** (コンバージョン計測用)
5. **Meta アクセストークン** (長期トークン推奨)
6. **Gemini API キー**

## 2. スプレッドシートの作成

### 2.1 新規スプレッドシート作成
1. Google スプレッドシートで新規ファイルを作成
2. ファイル名を「Meta広告自動化システム」などに変更

### 2.2 Apps Script プロジェクト作成
1. **拡張機能** > **Apps Script** を選択
2. 以下のファイルを作成し、コードを貼り付け:
   - `config.gs`
   - `main.gs`
   - `campaign.gs`
   - `analysis.gs`
   - `report.gs`
   - `notification.gs`

### 2.3 シート初期化
1. スプレッドシートに戻り、ページをリロード
2. メニューに「Meta広告自動化」が表示される
3. **Meta広告自動化** > **シート初期設定** を実行
4. 以下のシートが自動作成される:
   - 共通設定
   - キャンペーン設定
   - videos
   - analysis
   - 実行ログ
   - 昨日
   - 過去7日間
   - 直近1ヶ月
   - 直近3ヶ月

## 3. 共通設定の入力

「共通設定」シートに以下の情報を入力:

| 項目 | 値の例 | 説明 |
|------|--------|------|
| 広告アカウントID | act_123456789 | Metaの広告アカウントID |
| ページID | 987654321 | Facebookページの数値ID |
| InstagramアカウントID | 555555555 | IGビジネスアカウントID |
| ピクセルID | 111111111 | Meta Pixel ID |
| 年齢下限 | 18 | ターゲット最小年齢 |
| 年齢上限 | 65 | ターゲット最大年齢 |
| CPA上限 | 5000 | コストキャップ（円） |
| 通知メールアドレス | your@email.com | 結果通知先 |
| アクセストークン | EAAG... | Meta API トークン |
| GeminiAPIキー | AIza... | Gemini API キー |

## 4. Meta アクセストークンの取得

### 4.1 Meta開発者アカウント設定
1. https://developers.facebook.com/ にアクセス
2. アプリを作成（または既存のアプリを使用）
3. アプリに「Marketing API」を追加

### 4.2 アクセストークン生成
1. **ツール** > **Graph API Explorer** を開く
2. 対象のアプリを選択
3. 必要な権限を追加:
   - `ads_management`
   - `ads_read`
   - `pages_read_engagement`
   - `instagram_basic`
4. 「Generate Access Token」をクリック

### 4.3 長期トークンへの変換（推奨）
短期トークン（1時間）を長期トークン（60日）に変換:

```
https://graph.facebook.com/v21.0/oauth/access_token?
  grant_type=fb_exchange_token&
  client_id={app-id}&
  client_secret={app-secret}&
  fb_exchange_token={short-lived-token}
```

## 5. Gemini API キーの取得

1. https://aistudio.google.com/ にアクセス
2. 「Get API Key」をクリック
3. プロジェクトを選択してキーを生成
4. 生成されたキーを「共通設定」シートに入力

## 6. 使い方

### 6.1 キャンペーン作成

1. **Google Drive にクリエイティブを格納**
   - フォルダを作成
   - 画像ファイル（.jpg, .png）をアップロード
   - 動画ファイル（.mp4）をアップロード

2. **キャンペーン設定シートに記入**
   - キャンペーン種別: 「認知」または「リード獲得」
   - 店舗情報、住所、ターゲット半径
   - 予算、配信期間
   - LP URL、広告文
   - クリエイティブフォルダURL
   - ファイル名

3. **実行**
   - **Meta広告自動化** > **キャンペーン作成を実行**
   - 処理完了後、メール通知が届く

### 6.2 動画分析

1. **動画の書き出し**
   - **Meta広告自動化** > **動画をvideosシートに書き出す**

2. **分析実行**
   - **Meta広告自動化** > **動画を分析して書き出す**
   - Gemini が動画を分析し、結果を「analysis」シートに出力

### 6.3 レポート取得

1. **手動更新**
   - **Meta広告自動化** > **レポート更新（〇〇）**

2. **自動更新設定**
   - **Meta広告自動化** > **日次トリガー設定**
   - 毎日6時に全レポートが自動更新

## 7. トラブルシューティング

### よくあるエラー

| エラー | 原因 | 対処 |
|--------|------|------|
| 住所から座標を取得できません | 住所形式が不正 | 正確な住所を入力 |
| ファイルが見つかりません | ファイル名が不一致 | ファイル名を確認 |
| Meta API エラー: Invalid OAuth | トークン失効 | 新しいトークンを取得 |
| file not ACTIVE after polling | 動画が大きすぎる | 動画を短縮/圧縮 |

### ログの確認
1. Apps Script エディタを開く
2. **表示** > **実行ログ** を選択
3. エラー詳細を確認

## 8. 注意事項

- キャンペーンは「一時停止」状態で作成されます。配信開始前に必ず確認してください。
- アクセストークンは60日で失効します。定期的な更新が必要です。
- Gemini API には利用制限があります。大量の動画を一度に分析する場合は注意してください。
- 本番環境での利用前に、テスト用の広告アカウントで動作確認を推奨します。
