# Meta広告キャンペーン自動作成・分析システム 設計書

## 1. システム概要

Meta広告のキャンペーン作成から分析までを自動化するGoogle Apps Scriptシステム。

### 処理フロー

```
[手動] ドライブに動画を格納
        ↓
[手動] シートに動画URL・設定を記載
        ↓
[自動] GAS実行 → Meta広告に出稿
        ↓
[自動] 「videos」タブに動画情報を自動記録
        ↓
[自動] Geminiによる動画の定性分析
        ↓
[自動] Meta Adsレポート取得（日次トリガー）
```

### 2.5 レポートシート（4タブ）
- `昨日` : 前日のパフォーマンス
- `過去7日間` : 直近7日間
- `直近1ヶ月` : 直近30日間
- `直近3ヶ月` : 直近90日間

## 3. 機能モジュール

### 3.1 キャンペーン作成モジュール (`campaign.gs`)
- キャンペーン作成
- 広告セット作成
- クリエイティブアップロード（画像/動画）
- 広告作成
- videosシートへの自動記録

### 3.2 動画分析モジュール (`analysis.gs`)
- Gemini Files APIへの動画アップロード
- 動画の定性分析（構成要素抽出）
- 分析結果の正規化
- analysisシートへの書き込み

### 3.3 レポートモジュール (`report.gs`)
- Meta Insights API からのデータ取得
- 日次レポート生成
- 自動トリガー設定

### 3.4 ユーティリティモジュール (`utils.gs`)
- 共通設定取得
- 日付処理
- API呼び出しヘルパー
- エラーハンドリング

## 4. API連携

### 4.1 Meta Marketing API (v21.0)
- キャンペーン作成: `POST /{ad_account_id}/campaigns`
- 広告セット作成: `POST /{ad_account_id}/adsets`
- 画像アップロード: `POST /{ad_account_id}/adimages`
- 動画アップロード: `POST /{ad_account_id}/advideos`
- 広告作成: `POST /{ad_account_id}/ads`
- レポート取得: `GET /{ad_account_id}/insights`

### 4.2 Gemini API
- ファイルアップロード: Files API (Resumable Upload)
- 動画分析: generateContent with video input

### 4.3 Google APIs
- Drive: ファイル取得
- Maps: ジオコーディング
- Gmail: 通知メール送信

## 6. エラーハンドリング

### 6.1 リトライ戦略
- Meta API: 429/5xx エラー時に指数バックオフ（最大6回）
- Gemini API: ファイル状態確認で最大24回ポーリング

### 6.2 通知
- 処理完了/エラー時にメール通知
- スプレッドシートにステータス記録

## 7. セキュリティ考慮事項

- APIトークンはScript Propertiesに保存
- アクセストークンはスプレッドシートに直接記載しない運用を推奨
- 定期的なトークン更新が必要（Meta長期トークンの有効期限に注意）
